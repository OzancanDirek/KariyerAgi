# Üniversite ve bölüm seçenekleri

`universityPrograms.json`, [izcir/YokAPI](https://github.com/izcir/YokAPI) deposundaki `data/universities_departments.csv` dosyasından 29 Ekim 2026 tarihinde oluşturuldu. Kaynak, YÖK Atlas ve ÖSYM verilerinden derlenmiş 2019–2024 program kayıtlarını içerir. Depo MIT lisanslıdır; telif bildirimi aşağıdadır.

Copyright (c) 2025 IZCI — MIT License.

Türkiye dışındaki 16 kurum adları ayıklandı. Sonuç 214 üniversite ve 599 benzersiz bölüm adı içerir. Liste resmî, canlı YÖK API'si değildir; yeni kurum/programlar için dönemsel güncelleme gerekir. Eğitim formundaki “Diğer kurum / lise” ve “Diğer bölüm” seçenekleri listede olmayan kayıtlar içindir.
